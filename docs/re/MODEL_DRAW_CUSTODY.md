## Raw node admission

`WorldModelFog` preserves the parent integer fog pair separately from the GL
float pair. The existing successful loader and both Main Base B8/BC
frame-request sites publish it. `464E60` uses the owned current Sub-H/Sub-M
VIEW origin, unsigned radius, wrapping signed dword comparisons and local
header `0x20` before cache preparation or H/E callbacks:

1. Header `0x20` selects Near.
2. Signed wrapping `origin_z - radius >= far_raw` rejects the node.
3. Signed wrapping `origin_z + radius < near_raw` selects Near; equality and
   the remaining admitted cases select Fog.

body, edge and billboard buffering. GL does not reselect from its float
camera. Free/resize, intrinsic, explicit frontend fade and missing raw/frame

allocate `0x19000` bytes through `494860(&4D04E8,...)`; the error branch exits
