# Optional demo comparison data

This folder holds the separate private late-demo corpus (`PRELOAD.DAT` and
`OVERLAY/`). Everything except this note is Git-ignored. It is never a fallback
for the retail game. Demo-only tests and retail/demo comparisons are ignored
when the folder contains only this note or is empty.

Set `V2K_DEMO_DIR` to use a different demo installation. Relative paths are
repository-relative. See [the test setup](../README.md#building).
